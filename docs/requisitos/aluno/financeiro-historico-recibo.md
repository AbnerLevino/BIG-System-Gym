# Financeiro do aluno — histórico e recibo

**Módulo:** Aluno
**Ator:** Aluno
**Status:** Planejado (rota `/aluno/financeiro`) — confirmar implementação atual no código

## Descrição
O aluno deve conseguir visualizar o histórico de pagamentos e baixar o recibo (PDF) de cada pagamento confirmado.

## Regras de negócio relacionadas
- Recibo é gerado com numeração sequencial no momento em que o pagamento é aprovado — ver `docs/requisitos/admin/financeiro-calculo-pagamento-regras.md`.
